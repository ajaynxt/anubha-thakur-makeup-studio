# Anubha Thakur Makeup Studio

A responsive, single-page website for Anubha Thakur Makeup Studio, New Delhi.

## Included
- Mobile-first layout and WhatsApp enquiry links
- Services and indicative price ranges supplied for the studio
- SEO title, description, keywords and Open Graph basics
- Instagram portfolio link
- No third-party tracking scripts installed

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. GitHub Pages will show the published URL when deployment is ready.

## Before launch
- Replace the editorial artwork blocks with Anubha's approved original portfolio photographs.
- Confirm service inclusions, prices and availability with the artist.
- Add the final custom domain after its owner confirms the exact domain.
- Add Google Analytics / Search Console only after the property and tracking consent requirements are confirmed.
